# quench3d 生产可用性判定标准（分场景 · 可判定）

> **用途**：回答"能不能替代市面上的消费/生产软件"这类问题，把定性争论变成可复现的判定。
> **方法**：每个场景拆成 4 类门槛 —— `T` 进入门槛（Table stakes）、`Q` 质量标准（Quality bar）、`C` 规模化/协作门槛（Scale & collaboration）、`H` 隐蔽硬指标（Hidden，一票否决）。
> **判据**：每条都必须有"通过条件 + 验证方法"；写不出验证方法的条目按"未验证"处理，**未验证 = 不达标**。
> **quench3d 现状来源**：本仓库实读（`README.md` 1300 行、`docs/gap_analysis.md` 662 行、`crates/*/src` 37,013 行、`.github/workflows/ci.yml`、`web/pkg` 11 MB），2026-10-16 快照。项目自报的部分标 `[自报]`，未经独立复现。

---

## 0. 判定口径（先约定，否则无法判定）

| 结论档 | 含义 | 判据 |
| --- | --- | --- |
| **能替代** | 该场景的日常主流程可完全在目标软件内闭环，无需回退到对标物 | 该场景 `T` 全过 ∧ `Q` 关键项全过 ∧ `H` 全过 ∧ `C` 至少 1 条过 |
| **有条件替代** | 只在**可枚举的子集**内成立，子集外必须换工具 | 子集边界能用一句话说清（"当用户要做 Y 时必须换工具"）+ 该子集内 `H` 全过 |
| **不能替代** | 存在 `H` 未过，或 `T` 缺项导致主流程无法闭环 | 任一 `H` 未过即封顶 |

三条不可动摇的判定规则：

1. **`H` 一票否决**：隐蔽硬指标任一项未过 → 该场景直接"不能替代"，无论功能做得多全。理由：功能缺失用户看得见、能绕过；`H` 缺失在生产里表现为"间歇、不可复现、无法归因"，处置成本高一个数量级。
2. **证据分级**：`E1` 文档自报 → `E2` 本仓库可复现命令 → `E3` 与外部参考实现的对比数据 → `E4` 真实设备/真实用户矩阵。关键项要判"能替代"必须 ≥ `E3`。
3. **不可跨场景加总**：`N/M` 计数只在同一场景内有效。S3 的确定性不能抵消 S1 的色彩管理缺位。

## 1. 3D 模型查看 / 检查与轻量编辑
对标：Blender 视口、Windows 3D 查看器、glTF Viewer、Sketchfab。
**"生产"定义**：别人丢给你一个模型文件，你要在无人协助下打开、看清、判断它能否进下游，并把结论交给别人。

| ID | 门槛条目 | 可判定判据（通过条件 + 验证方法） | quench3d 现状 |
| --- | --- | --- | --- |
| S1-T1 | 格式覆盖面 | glTF2.0/GLB 跑通 Khronos 官方 Sample Models 全量（含 Draco、KHR_materials_*、sparse accessor）并记录通过率；OBJ/STL/FBX/USDZ 至少再 2 种 | glTF/GLB/OBJ+MTL；无 Draco/KHR 扩展清单、无 FBX/STL/USDZ、无官方模型集通过率 [自报] |
| S1-T2 | 检视工具 | 轨道/平移/缩放/聚焦；线框/**法线**/包围盒/统计面板（顶点·三角·材质·贴图尺寸·UV 集·非流形边） | `model_viewer` 示例有轨道相机；`quench3d info` 输出统计（CLI 侧）；编辑器 doc 层只认 4 种预设网格，导入模型不可编辑 |

| S1-Q1 | 与参考渲染器一致 | 同相机/光照/色调映射下与 Blender EEVEE 或 Filament 参考图对比：SSIM > 0.95 或 ΔE2000 中位数 < 3 | **无任何图像 golden**：单帧 `render` 只断言"是合法 PNG"，无像素基线；色调映射只有一条 ACES 路径，不可选 |

| S1-H1 | 色彩管理 | 声明工作色彩空间、贴图/顶点色/自发光的传递函数、PNG 导出是否写 sRGB chunk；sRGB 与广色域显示器观感一致（有说明且可测） | 只有内部约定（材质色 sRGB、点光线性）；无 ICC/广色域策略、无导出色彩标记 → **未过** |
| S1-H2 | 单位与坐标系 | 导入时读取并应用单位与 up-axis（Y/Z-up）、手性；不一致必须显式告警而非静默 | CLI 场景单位已声明（米/秒/度）；导入侧无 up-axis/单位策略 → **未过** |
| S1-H3 | 坏文件与格式演进 | 截断/损坏/未知扩展名不崩溃且报错含文件内定位；旧版本文件在新版本可读（有回归用例） | 场景 JSON 有 `version:1` + JSON 路径诊断 + 一次返回全部问题；模型加载侧无损坏文件测试集 → 未验证 |

**判定：不能替代** Blender 视口 / Sketchfab（`S1-H1`、`S1-H2` 一票否决，`S1-Q2` 静默损坏数据）；**可替代** "无头模型体检 + 批量出缩略图"这一窄子集。

**"生产"定义**：把设计数据变成可信的、能交给甲方看的画面，并且每周重出一版。

| --- | --- | --- | --- |
| S2-T1 | 设计数据交换 | glTF/USD/IFC/FBX/OBJ 至少 3 种；保留层级、材质、单位、对象名与元数据；同模型两次导入结果一致 | glTF/GLB/OBJ；无 USD/IFC/FBX；**导入时 glTF 的节点层级被展平**（每个 primitive 一个物体，节点变换不外传）；场景自身的父子层级已具备（2026-10-17 第 16 轮，`objects[].parent`）；对象名保留 |

| S2-T3 | 出图与出片 | 正交/透视 + 焦距/感光/EV 锁定；4K 批量；全景/序列/相机路径 | 离屏 PNG、`movie`（PNG 序列 + trace.jsonl + 内置 GIF/APNG）；相机 `near`/`far`/**正交**（`orthographic_height`）已进场景格式（`camera.*`）；**仍无**多相机/多视口、全景、相机路径、焦距/感光/EV 锁定 |
| S2-Q1 | 观感与帧率 | 具备 IBL + 接触阴影（SSAO/AO）+ CSM；1080p 中端独显 ≥ 30fps；离线 4K 单帧 ≤ 2min | SSAO ✅（深度-only、无去噪）+ FXAA ✅；仍无 CSM/IBL/TAA/DOF；无独显实测（软件光栅 ~1.06s/帧）→ **不达标** |
| S2-Q2 | 尺度 | 10⁵ 实例可交互、10⁶ 可加载；无 LOD/遮挡剔除即不达标 | 有实例化 + 视锥剔除；**无 LOD、无遮挡剔除**，逐实例线性剔除 |
| S2-Q3 | 光照一致性 | 同场景跨视角/跨时间光照一致，无阴影闪烁；大场景需 CSM | 单张阴影贴图，> 100m 场景阴影糊掉（项目已自认） |

| S2-C2 | 大场景增量 | 保存时间不随体量爆炸；可流式/分区加载 | 无流式、无分区；场景 JSON 随物体数线性膨胀 |

| S2-H2 | 确定性与版本漂移 | 同场景同参数出图逐位可复现；引擎升级若改变画面必须有 golden 断言拦下 | **强项**：`movie` 已断言两次录制像素摘要一致（`fnv1a64`）、断点续录、换编码器不改 digest；但单帧 `render` 无 golden |

**判定：不能替代** Twinmotion / Enscape / Datasmith（观感、光照真实性、BIM 交换、协作四线同时不足）；**可替代** three.js 应用中"白模/静态演示 + 批量出图 + 回归门禁"子集。

## 3. 物理仿真 / 工程仿真
对标：MuJoCo、Isaac Sim、PyBullet、Project Chrono。
**"生产"定义**：结论要能写进报告并被人复核 —— 别人用同样输入必须得到同样的数字。

| ID | 门槛条目 | 可判定判据（通过条件 + 验证方法） | quench3d 现状 |
| --- | --- | --- | --- |
| S3-T1 | 数值口径 | SI 单位与坐标系自描述；固定步长可配；公开积分器与误差量级（对自由落体/简谐振子解析解对比） | 半隐式欧拉，项目自报自由落体 1s 位置误差 ≈1.6%；单位在 CLI `schema` 中声明 |

| S3-T3 | 关节与驱动 | ≥5 类关节 + 锚点 + 限位 + 马达/伺服 + 多体链（articulation） | 5 类关节具备；**Ball 无限位、仅 Hinge 有速度马达、无位置/伺服马达、无 6DOF、无 break force** |

| S3-Q3 | 非物理伪影 | 静置抖动、热启动丢失、1e-4 边界闪断均有回归用例 | `ContactPoint` 无特征 ID，缓存按刚体对 + 局部锚点 0.02 容差就近匹配 → 4 层以上堆叠下沉抖动（项目自认） |

| S3-H4 | 单位 / 惯量 / 几何来源可审计 | 解析惯量 vs 网格惯量、凸包近似误差必须显式告警 | 凸包近似已有告警；惯量来源未在输出中标注 |
| S3-H5 | 验证 vs 确认（V&V 两个 V） | 文档必须分开写"代码做对了"与"模型是否代表现实"；软件只负责前者 | 无该分层表述 |
| S3-H6 | 许可与专利 | 求解器与编解码许可清单（GPL / 专利池） | **优势项**：MIT OR Apache-2.0 双许可全文入库、物理零第三方依赖 + `forbid(unsafe_code)` |

**判定：不能替代** MuJoCo / Isaac / Chrono（`S3-Q1`、`S3-H1`、`S3-H2` 三条同时阻断）；**可替代** "确定性刚体参数扫描 / CI 回归 / 教学演示 / agent 可调用的物理服务"。

## 7. "什么程度算能替代 X" 的判定规则

**折算流程（按顺序，前一步出局就不必看后面）**：

| 步骤 | 动作 | 产出 |
| --- | --- | --- |
| 1 | 用对该标物的 `H` 列做一票否决过滤 | 得到"可能能替代"的场景集合 |
| 2 | 在剩下的场景里要求 `T` 全过 | 主流程能否闭环（不能闭环 = 不构成替代） |
| 3 | `Q` 关键项全过 → "能替代"；部分过 → "有条件替代" | 结论档位 |
| 4 | `C` 决定这是"生产软件"还是"单机工具" | 不能规模化 → 只能算工具，不算替代 |

**具体目标的必过项（缺一即不能替代）**：

| 目标 | 必须项（缺一即不能替代） | 单项门槛（可判定） | 常见的"看起来像但不算" |
| --- | --- | --- | --- |
| 替代 Blender 的**视口查看/检查** | 无损往返 + 色彩管理声明 + 官方 glTF 模型集 100% 通过 + UV/法线/材质检查工具 + 1M 面 30fps | 往返 UV 误差 < 1e-6；对比参考图 SSIM > 0.95；10M 面可打开 | 能显示 ≠ 能检查（没有 UV/非流形/法线检查就不算） |
| 替代 Blender 的 **UV** | 展开算法 ≥ 2（LSCM/ABF 级）+ 接缝标记 + 钉住/固定 + 多 UV 集 + UDIM + 按岛/材质打包 + 编辑撤销 | 10 万面展开 < 5s；往返误差 < 1e-6；UDIM 1001+ 可用；打包无重叠 | 智能投影 / 立方投影 ≠ UV 展开 |
| 替代 Blender 的**雕刻** | 多级分辨率或动态细分 + ≥ 8 类笔刷 + 对称 + 遮罩/面组 + 重拓扑减面 + 大面数交互 | 1000 万面交互 ≥ 15fps；笔刷到画面 < 16ms；撤销不随面数线性爆内存 | 顶点位移笔刷 ≠ 雕刻 |
| 替代 Blender 的**布尔** | 稳健内核（精确/自适应）+ 非流形/共面/自交处理 + n 边形输出 + 结果水密 + 可撤销 | 1000 个病态用例 0 崩溃 0 卡死；结果水密；体积误差 < 0.1% | 凸包近似、"能切一刀" ≠ 布尔 |
| 替代 Blender 的**修改器栈** | ≥ 20 个常用修改器、生成器/变形/物理三类齐、非破坏顺序、可应用可烘焙、与实例/曲线交互、可脚本化 | 任意组合可确定性重算；存盘重开结果一致 | 只有"应用一次"的操作 ≠ 修改器栈 |
| 替代 Blender 的**建模整体** | 上述 4 项全过 + 撤销/重做（深度与内存上限）+ blend/glTF/FBX/USD 往返 + 脚本 API + 插件生态 | 1GB 场景开/存 < 30s；撤销 100 步可用 | 能建方块/球 ≠ 建模 |
| 替代 **Unity / Godot** | 动画（蒙皮 + 状态机）+ 音频 + 输入映射 + UI + 存档（含迁移）+ 三平台发布流水线 + 崩溃上报 | 60fps 且 1% low 稳定；旧档可读；商店合规无阻断 | 能跑物理 demo ≠ 游戏引擎 |
| 替代 **MuJoCo / Isaac / Chrono** | 关节/驱动完整（限位/伺服/多体链）+ 接触模型（静动摩擦/持久流形/多点）+ V&V 基准报告 + 接触力导出 + 确定性边界声明 + Python/C API | 基准误差达阈值；深堆下沉 < 2mm；确定性边界与环境一并写明 | 能堆箱子 ≠ 工程仿真 |
| 替代 **three.js / Babylon** | 首屏 ≤ 3s + 真机兼容矩阵 + 后端一致性量化 + 可访问性 AA + 版本化缓存与回滚 | br 后首包 ≤ 2–5MB；移动 30fps；矩阵通过率 ≥ 95% | 能出图 ≠ 能上线 |
| 替代 **Blender 无头 + Python 批处理** | 无头确定性 + 机读契约 + 幂等 + 产物哈希门禁 + 可复现构建 + 许可清单 | 同输入两次产物 digest 一致；坏输入退出码固定；启动 < 50ms | 有 CLI ≠ 能进流水线 |
| 替代 **ffmpeg 流水线** | 编码覆盖与质量 + 时间基/帧率语义 + 色彩元数据传递 + 断点续跑 | 时长严格 = 帧数 × 步长 × dt；色彩标记不丢 | 能出 GIF **不能**替代 ffmpeg（正确做法是对接） |

## 8. 结论模板

**一句话句式（必须填空，不许形容词）**：

> quench3d 在 **【场景 S?】** 上 **{能替代 | 有条件替代（子集：___） | 不能替代}** **【对标物】**；
> 依据是达标 **N/M**（列出 ID），阻断项是 **【ID】（`H` 类一票否决）**。

**输出表格（缺一列都不算完成判定）**：

| 字段 | 填什么 | 判据来源 |
| --- | --- | --- |
| 场景与对标物 | 场景编号 + 明确对标物版本 | 本文件 §1–§6 |
| 结论档 | 能替代 / 有条件替代（子集边界一句话）/ 不能替代 | §0 判定规则 |
| 达标 ID | `T`/`Q`/`C` 达标清单 + 计数 N/M | §1–§6 表格 |
| 阻断 ID | `H` 类未过清单（这一列决定结论） | §1–§6 表格 |
| 证据等级 | 每个关键项的 E1–E4 | §0 规则 2 |
| 剩余风险 | 按"上生产后多久爆炸"排序 | 见下方风险表 |

**剩余风险表（模板 + quench3d 已填）**：

| # | 风险 | 触发场景 | 后果 | 证据缺口 | 关闭条件 |
| --- | --- | --- | --- | --- | --- |
| 1 | 色彩管理缺位 | 任何"比对颜色"的用途 | 结论不可信且无人发现 | 无 ICC/传递函数/导出标记说明 | 写明工作空间 + 出图带标记 + 一张 sRGB/广色域对照用例 |
| 2 | 单帧无图像 golden | 每次渲染改动 | 画面静默漂移流到交付物 | CI 只查 PNG 头 8 字节 | 单帧像素基线进 CI |
| 3 | 导出丢贴图引用 | 场景被"再存一次" | **静默数据损坏**，比崩溃更贵 | 无往返测试 | 往返测试断言贴图字段不丢 |
| 4 | 无 CHANGELOG / 迁移器 | 场景格式升级 | 下游流水线无预判被中断 | `version:1` 但无迁移路径 | `CHANGELOG` + 格式迁移器 + 旧文件读取用例 |
| 5 | 可复现构建缺门禁 | 升级依赖/工具链后 | "昨天还一样"的结果变了，无法归因 | 无 `rust-toolchain.toml`、`--locked` 未进 CI、无 `deny.toml` | 三者进 CI + golden digest 复跑 |
| 6 | 11MB wasm + WebGPU 真机未验 | Web 上线首日 | 真实设备打回 | 仅 headless Chrome + SwiftShader | 真机矩阵 + br 后体积预算 |
| 7 | 单点流形 / 无接触力导出 | 被当工程仿真用 | 精度结论不可审计 | 无基准 V&V、无接触冲量 | 基准套件 + 接触 ID/力导出 |
| 8 | 密钥处理的回归风险 | 每次改动 LLM 链路 | 凭证泄漏 | 已有假 curl 反证测试（防线在） | 把该测试设为必过门禁并保持 |
| 9 | 物理层可观测性为零 | 病态输入导致数值夹紧 | 问题静默，无人能定位 | 物理 crate 无 `log` 依赖 | 引入结构化日志 + 帧阶段计时 |
| 10 | 错误码只有 4 类 | agent 编排分支 | agent 只能读自由文本，不可靠 | 无细粒度 `error.kind` | 细分错误码 + `outputSchema` |

**最终一句话结论（quench3d，2026-10-16 快照）**：quench3d 目前是"**确定性刚体仿真内核 + agent 友好的无头内容流水线**"的垂直切片，可在 **S6 的窄子集**替代自建 Python 胶水、在 **S3 的窄子集**替代教学/回归用途；在 **S1/S2/S4/S5** 的任何一个对标物上都不构成替代关系 —— 阻断点不是功能数量，而是**色彩管理、无损往返、可复现构建、真实设备矩阵**这四类"看不见的硬指标"。
